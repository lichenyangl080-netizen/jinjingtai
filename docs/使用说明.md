# 进境台使用说明

进境台是 Windows 本地工作进展记录工具。主要入口为工作台、项目、回望；工作台顶部常驻今日/日历切换。设置固定在侧栏底部，分为 Codex连接、资料与备份、阅读。

## 新版阅读与组织

首次连接时可在设置的“完成首次接入”中检查 Codex 程序版本与登录状态。选择资料库、保存连接与核对范围后，在 Codex 中完成 Hook 信任、重启并打开新工作聊天；选择“等待新回执”，正常工作收尾后检查新的真实记录。无新增变化的回执也可证明连通。环境检查不调用整理模型，页面确认信任不代替 Codex 授权，旧回执不算本次成功。

本次软件会话中，切换工作台、项目或设置分类会保留环境检查结果和等待回执的基线。切换资料库、撤销连接或明确重新等待会重置相应会话；退出并重开软件后需重新等待。

主线编辑可主动选择“包含可读历史判断”，把被否定或替代的旧路线补进同一过程，历史状态持续保留。继续起点仍只摘取当前有效下一步。

回望编辑左侧阅读和预览材料，右侧保留自由正文；小窗口用“写正文／读材料”切换，草稿不会因为核对记录而退出。可以预览变化、下一步和更正，再引用当前记录。详情中的“用于起点、主线或回望…”可直接摘取、明确移动到同项目主线，或追加到记录所在周/月/年回望，保留已有正文。

回望事项每批显示200件，可继续加载；筛选会查完整周期，详情连续阅读也覆盖完整结果。加载范围按资料库和周期记忆。超过首批的起点来源、主线成员及回望引用显示“已显示 / 总数”，不截断保存内容。

引用和主线的关键词筛选包含下一步。回望编辑时也提示失效引用；可读引用显示所属项目，同名项目附目录，搜索结果使用相同区分信息。新补记保存后独立阅读，不沿用之前搜索的记录序列。

工作台会记住最后使用的今日或日历；项目的定位月份和已加载范围在跨页及重新打开后保留，各资料库分别记忆。继续起点可单独按内容类型搜索，并按其保存工作日筛选，不使用概况的旧日期。

主线和回望引用会提示已有后续否定或替代，可直接查看真实更正。起点来源成为历史结论后仍可追溯；隐藏或移除的正文不会重新显示。折叠主线显示记录数、日期跨度和不可用引用，展开每次显示50条，详情上一条/下一条可沿整条主线阅读。

侧栏搜索可按本地正文关键词找回记录，也覆盖每日心得、人工项目概况、继续起点、周期回望和主线说明。空格分隔关键词必须全部命中；依据文本和历史结论分别显式勾选，结果每页50项。不读取原始聊天、外部目录或附件正文。

项目按人工概况、继续起点、最近变化、事项主线/全部历程组织。未填写概况时提供一行写作入口；保存概况后新增的旧日记录也会列入最近变化。起点可手写或从有效记录下一步摘取，摘取后保存副本及来源；只提醒摘取后的来源变化，不自动更新行动。历程默认显示最近三个有记录月份，可定位年月或加载更早。

事项主线由你选择同项目记录组织，不按同名自动合并；每条记录至多属于一条主线，重复分配明确移动。已有成员成为历史结论后仍可解除关联。归档只停止组织，删除只解除关系，不改变记录及验证状态。搜索主线直接展开并定位该主线。

周、月、年回望可以自由填写正文并引用本期记录。提示可忽略，心得不自动填入正文，没有AI回望或成长评分。引用记录日期纠正后仍可打开，并保留摘取时的日期；引用不可用时保留标题和日期。主线、起点和周期正文不进入整理模型。

工作台“其他日期待整理”可进入积压日期，每次仍显式选择一个工作日和材料范围。详情提供所属列表内的上一条/下一条及展开阅读；关闭按钮或Escape均回到原列表或查询。未保存编辑在切页、切记录、切库时统一保护，保存失败保留输入。

首次在正式库使用新版前，先在“设置 → 资料与备份”创建可恢复备份。旧客户端编辑新人工字段没有默认兼容保证；回退时使用升级前备份副本。

## 第一次打开

解压整个发行包，在普通可写文件夹中运行 `进境台.exe`，不要只复制 exe，也不要直接在压缩包内运行。

点击“创建或选择资料库”，选择保存记录的文件夹。未连接 Codex 时也可以补记、编辑、保存和回望。已有库缺失或损坏时，软件会停止写入并提示检查，不会自动重建空库。

## 连接 Codex

先安装并登录自己的 Codex。进入“设置 → Codex连接 → 设置连接”，选择资料库与采集范围，随后在 Codex 中审阅并信任新增 Hook，重启 Codex。软件不会要求填写 API Key。

本地来源按实际数据契约识别，版本号变化本身不会拒收。字段、状态或来源身份不明时显示历史扫描缺口；已有记录仍可阅读和编辑，可信 Hook 的新阶段保存独立核准。历史佐证不可用时不把未验证内容升级为已验证。

采集只记录授权目录的正常工作收尾，排除资料库、配置、运行目录和内部整理任务。不会补读完整历史聊天。关闭进境台窗口后 Hook 仍可记录，整理需要你主动发起。

## 记录与整理

点击“补记一件事”，填写标题，保存即可。记录可编辑、移除和附加本地附件；已移除记录在“设置 → 资料与备份”中恢复。新建项目、规划与正文编辑在离开前会检查未保存内容。

正常 Codex 工作产生新材料后，选择日期，点击“整理这一天”，核对来源范围后开始。结果通过检查后直接保存，没有二次确认或审阅草稿流程。无新增不调用模型，失败不会自动重试。人工正文、回顾、规划和附件不进入整理模型。

日历每天凌晨4点按上海时间切换工作日。未来一个月内可以写手动规划，规划不会作为已完成成果。

## 保存位置、备份与恢复

默认状态配置在当前用户 LocalAppData 下的 `Jinjingtai`。资料库保存权威 JSON 和本地附件；SQLite索引可重建，不是正文权威。

“设置 → 资料与备份”可打开保存位置、创建备份和选择另一资料库。切库不搬移、不合并原内容，也不改变采集范围或暂停状态。另一窗口切库后，旧窗口的保存会停止；请先保留输入，再重新读取目标资料库。避免多个软件副本共用同一资料位置。

备份不包含 Codex 登录凭据。成功备份有 `backup-complete.json`；`.incomplete` 表示未完成。恢复时将备份中的资料库复制到普通文件夹，打开副本；不要直接继续写入备份本体。

目录或记录文件异常时，请先核对磁盘位置或恢复副本，再点击“重新读取”。软件不会通过清空资料来修复异常。撤销连接只移除进境台的接入，已有资料保留；删除程序前请确认资料库和备份位置。

## 阅读与运行范围

“设置 → 阅读”修改正文大小，自动保存，覆盖记录、回顾、项目概况与编辑正文。软件保持统一黑白水墨布局。

发行包内置运行组件，本地手写与阅读无需另装 Node。源码开发使用 `.node-version` 指定的 Node 24.19.0；完整 Node 许可随包保存在 licenses 目录，打包时核对实际运行时版本。当前提供 Windows 桌面构建。尚未在另一台全新电脑完成真实 Codex 安装到整理的全部验收；不声明 macOS/Linux 或其他 Codex 版本已支持。

重新分享时请使用原始分享包，不要转发使用过、已产生个人配置的程序目录。自身代码采用仓库 LICENSE 中的 MIT 许可；第三方许可见 THIRD_PARTY_NOTICES.md 和发行包 licenses 目录。

搜索结果显示历史结论、命中字段和各关键词片段；进入结果定位正文。连续阅读切换从开头开始，导航固定在阅读区顶部。主线展开及加载数量按资料库和项目保留，已关联记录分批显示，保存保留全部关联。

项目的“事项主线／全部历程”选择和各自阅读位置分别记忆；搜索定位完成后，普通返回遵循手动展开与折叠。更改搜索词或筛选时等待新结果，旧结果不再可点击。

回望编辑先写正文和保存，需要引用时展开“选择引用记录”。筛选控件独立排列，历史结论就地提示；候选和已选引用分批显示，保存仍保留全部选择。起点来源可按标题或下一步关键词筛选，并加载更多来源。记录内部的来源补充保留在原始依据中，不作为指向自身的后续记录显示。
