# 历史材料：进境台桌面界面原型

本说明只保留早期原型行为，不适用于现行产品。当前功能与开发步骤见仓库 README.md。

见日有所行，知身有所至。

这是一个在 Windows 独立窗口里运行的桌面软件原型。双击产品文件夹里的“打开进境台”快捷方式即可使用，无需浏览器、账号或服务器。界面使用黑白水墨风；当前使用虚构样例，尚未连接 Codex。

## 打开

推荐双击 `E:\ChatGPT\进境台\打开进境台.lnk`。

也可以进入 `E:\ChatGPT\进境台\desktop\release\进境台`，双击 `进境台.exe`。请保持这一整个目录完整，运行时需要其中的 DLL、resources 等文件。

## 使用

| 入口 | 用法 |
| --- | --- |
| 今日 | 查看按项目分组的进展。点一行打开右侧详情；点“查看依据”展开样例摘录。 |
| 补记一件事 | 日期按当前浏览日预填。写下做了什么，选择项目，结果和下一步选填，点“保存补记”。人工补记直接视为已确认。 |
| 编辑记录 | 点详情右上角的铅笔按钮进入编辑；底部保存或取消。修改草稿仍保留待确认状态。 |
| 确认今日回顾 | 确认本日待确认记录的准确性。确认不代表项目任务已经完成；提示内可撤销。 |
| 日历 | 点击日期先看右侧摘要，再点“查看这一天”，进入当天统一补记和编辑。小点表示有记录，细圈表示今天；选中日为黑底。 |
| 项目 | 左侧选择项目，右侧按当前状态、下一步、进展历程阅读；“补记进展”预填当前项目。更多菜单里的“编辑项目概况”同时编辑状态和下一步。 |
| 回望 | 切换周、月、年，只回看已确认的记录。点记录看原文，点“进入项目”继续查看。 |
| 设置 | 查看原型说明；先确认今日，再“追加待确认样例”，体验“确认新增记录”。 |

体验空白日期：在日历选择 2026 年 10 月 1 日，进入这一天，再补记。演示的“今天”固定为 2026 年 10 月 4 日。

“编辑回顾”统一编辑“今日所得”和“留给明天”，一次保存两项。当前版本已缩小字体和按钮，并减少阅读区域内的重复入口。

切换页面、日期、记录或关闭窗口时，如果有未保存的输入，会提供“保存并离开 / 放弃修改 / 继续编辑”。单纯阅读和确认记录不额外弹确认。编辑时整日确认会暂时禁用。

记录更多菜单里的移除可撤销；撤销提示消失后，也可以在本日列表下方恢复移除的记录。Esc 关闭详情或处理未保存内容；Ctrl+Enter 保存编辑。记录列表支持上下方向键和 Enter。

## 数据和当前范围

当前的补记、修改和确认状态保存在原型专用的本地存储，重开窗口仍可查看。便携发行版的数据目录为 `desktop\release\进境台\resources\app\.local-data\profile`；开发启动的数据目录为 `desktop\.local-data\profile`。验收使用单独的 qa-profile，不会修改使用者的样例。

本轮完成界面与交互验证。正式 JSON 日记录、SQLite 索引、备份、Codex 采集和每日整理尚未实现，留到界面确认后的接入阶段。原型未读取这台电脑上的真实 Codex 会话，也未调用模型。

## 二次开发

- `src/Workbench.tsx`：四个页面、共享详情面板和编辑流程。
- `src/model.ts`：样例与记录状态规则。
- `src/workbench.css`、`refinements.css`、`structure-refinements.css`：基础布局与视觉校正。
- `public/assets/`：本地字体、水墨插画、墨圈、按钮和竖线。
- `electron/`：桌面窗口、关闭保护和原生界面验收。
- `tests/records.test.mjs`：确认、编辑、补记与日期边界测试。
- `design-qa.md`、`qa/`：视觉比较和操作检查证据。

开发机器安装 Node / npm 后，在本目录执行：

```powershell
npm install
npm run check
npm run build:desktop
npm start
```

生成便携 Windows 发行目录：先 `npm run build:desktop`，再 `npm run package:desktop`。

当前采用 React + TypeScript，Electron 作为界面验证的桌面外壳。正式产品仍可迁移到原定的 Tauri；界面组件和记录规则可保留。当前电脑没有 Rust 编译环境，因此本轮没有构建 Tauri 软件。

外层 engineering-notebook 原始源码和许可证保持原样。它的解析、扫描和按日分组模块留待连接 Codex 时评估复用，本轮没有运行其采集与总结程序。
